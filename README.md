# National Skateboarding Skate Off Version 2

- Getting started with Google's Antigravity. Getting into the flow of building a project with the IDE for the first time.

- Prompted Antigravity to build a website for a skateboarding competition. It took me step by step through the process of building the project and asked if I accepted the changes.

- It was interesting seeing Antigravity do its work and create a website within seconds. Antigravity built the project and I decided to rebuild it from scratch. I took the UI it built and reimagined it and created my own version of the project.

# Built with

- React.js
- Vite
- CSS
- Tailwind CSS
